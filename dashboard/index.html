How the radar scores

Implied value = TVL × category multiple × growth × age × breadth. The multiple is the median market-cap/TVL of the token-bearing protocols in the same category, shrunk toward the global median so thin categories stay honest. Growth comes from the 7-day TVL change, age from how long the protocol has run with no token recorded, breadth from how many chains it operates on. Nothing is ranked by name: the board is a function of the snapshot.

Data: sealed DefiLlama snapshot, . “Records no token” means the snapshot records none — not proof the protocol has none. An implied value is this radar’s own claim about what a launch would be worth if the protocol’s record stayed as it is; it never predicts whether or when a token is issued.
